# Archivo de la edición local 4.2.1

Estos paquetes se conservan para identificar y mantener instalaciones existentes.
**No son el instalador de la aplicación cloud actual.** Para nuevas cuentas,
[abre OfiGremio en la nube](https://ofigremio-production.up.railway.app).

Última actualización de estos archivos: 30 de octubre de 2026.

| Archivo antiguo | Uso original |
|---|---|
| [Windows ZIP](OfiGremio_PRO_v4.2.1_Windows.zip) | Instalación de servidor local con Python |
| [Linux ZIP](OfiGremio_PRO_v4.2.1_Linux.zip) | Instalación de servidor local con Python |
| [Actualización de código](OfiGremio_PRO_v4.2.1_UPDATE_Solo_Codigo.zip) | Actualización de instalaciones locales de esa generación |

El lanzador local abre localhost y utiliza los datos de ese ordenador. Sus
usuarios, licencias y base de datos no se transfieren a Railway ni a tu cuenta
cloud al abrir el navegador o instalar una PWA. Estos ZIP no incorporan los cambios
posteriores de SaaS, almacenamiento y endurecimiento de seguridad.

Antes de modificar o migrar una instalación existente:

1. Conserva la carpeta original y realiza una copia consistente de su base SQLite,
   incluyendo los documentos y la licencia necesarios para su recuperación.
2. Identifica qué empresa posee los registros y qué usuarios pueden acceder.
3. Planifica una migración validada, con conservación de clientes, presupuestos,
   facturas, relaciones e identidad fiscal histórica. Verifica el resultado antes
   de abandonar el sistema anterior.

No reemplaces una base de datos real con una base limpia de un ZIP. No subas datos
comerciales, certificados ni contraseñas a este repositorio público. El archivo de
estos paquetes no supone que estén actualizados, recomendados para nuevas
instalaciones o aceptados para el despliegue SaaS actual.
